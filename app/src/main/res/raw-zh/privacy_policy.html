隐私政策

JTR — Just To Remember  ·  最后更新：2025年5月

摘要：JTR 是一款 100% 本地化应用。您的个人数据永远不会离开您的设备，城市地理编码（Nominatim）除外。

1收集的数据

应用程序存储以下信息，仅用于管理您的联系人：

  • 名字、姓氏、性别
  • 生日
  • 居住城市及关联的 GPS 坐标
  • 社交网络个人资料链接
  • 籍贯、兴趣爱好和个人备注
  • 头像照片（本地存储）

2数据存储

✓ 100% 本地 — 您的所有数据均通过 SQLite 数据库（Room）独家存储在您的设备上。不使用任何远程服务器。

✓ 永久删除 — 卸载应用程序将永久删除所有关联数据。

3位置使用

位置权限仅用于邻近提醒功能：

  • 计算您的位置与联系人城市之间的距离（Haversine 公式）
  • 当您靠近一个长时间未联系的联系人时，触发本地通知

✓ 不会将任何位置数据传输给第三方，也不会存储在您设备以外的地方。

您可以随时禁用此功能：设置 → 邻近提醒。

4第三方服务

Nominatim（OpenStreetMap）

搜索或选择城市时，城市名称会发送至 Nominatim API 进行地理编码。不会传输任何个人数据。

使用政策：nominatim.org

✓ 应用程序中未集成任何其他第三方服务（分析、广告、崩溃报告）。

5通知

JTR 的通知完全在本地产生，不经过任何服务器：

  • 生日提醒 — 在当天本地触发
  • 邻近提醒 — 通过 WorkManager 或 Geofencing 在本地触发

6您的权利

  • 访问和修改 — 您的所有数据均可在应用程序中查看和编辑
  • 删除 — 任何联系人或分类均可删除（30 天回收站）
  • 永久删除 — 卸载应用程序将清除所有数据
  • 权限控制 — 可随时在 Android 设置中撤销位置和通知权限

7未成年人

JTR 不会故意收集 13 岁以下人员的数据，也不针对此类用户群体。
